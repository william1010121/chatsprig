# ChatSprig 2.1.1 demo

這段 29 秒的 demo 展示 ChatSprig 在實際文章頁面中的核心流程：

1. 閱讀 Wikipedia 文章。
2. 按下 macOS `Option+K` 開啟 ChatSprig。
3. 輸入問題並按下 `Enter`。
4. 讀取 ChatGPT 回覆，再按下 `Option+K` 回到原頁面。

影片使用實際的 ChatSprig 2.1.1，畫面只擷取網頁內容，因此不包含 Ego Browser 的工具列、藍色邊界或 agent 游標標籤。影片沒有麥克風錄音，也沒有私人對話資料。
